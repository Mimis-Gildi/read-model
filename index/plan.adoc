= Wiring the Kotlin harness

Five architectural faults; the rest are consequences.

1. It's a singleton with hidden global state, constructed at import.
fixture is lateinit var; darkened, nodesOnScreen, teardown are file-level vars; dataset/run/module are parsed from window.location at module-load. There is no harness object — the module is the instance. You cannot construct two, and you cannot construct one without a page
already existing. That's why the test has to build the DOM in beforeEach and then jest.resetModules() before every import: the import itself is the constructor. Untestable by construction, not by oversight.

2. The DOM contract exists only as string literals scattered through this file.
tree, start, expandAll, collapseAll, status, rows, reveal, datasetKey, tr[id^="level-"], .node.collapsed, .kids, .row > .twist. Nothing declares them. Every fixture's index.html has to independently reproduce a contract that is never stated anywhere — which is exactly what
your // ToDo: Did I get it all? is asking, and the answer isn't knowable from any single place. The bench page is harness property; it's currently copied per module.

3. Control flow is driven by presentation markup.
ladderRows() decides how many rungs to run by counting <tr> elements. rungOf(row) then reads the rung's name back out of a table cell and files it to the service as the report key. The shape of the experiment is being read off an HTML table. The ladder is a property of the
model's depth; the table should be a rendering of the result, not the source of the run.

4. The model is deliberately erased at the boundary.
attach(company: dynamic), and census hand-walks divisions → groups → teams → people as Array<dynamic>. The model is Kotlin, serialized by kotlinx — the harness throws that away and hands raw parsed JSON across. Everything downstream pays: census re-implements the model's shape
a fourth time, and on the TS side it forced the entire Wire<T> mapped-type apparatus, which exists only to reconstruct the types this line discarded. Deserialize into Company and both problems disappear.

5. Measurement and presentation are fused.
ladder(), reveal(), collapseAll() each interleave clocking, status-string writing, cell-filling, button-disabling and socket-posting in one body. There's no seam to run the ladder headless, from a test, or under the control plane's direction. measure() is the only function
that's nearly pure, and it still writes a status line and recurses.

  Consequences, not separate faults: measure's unbounded self-recursion on darkened (hidden tab re-enters forever, and the onScreen()/darkened = false pair races); reveal's six mutable locals; Fixture.batch as a nullable member instead of a default; host exporting as {get()}
  because it's a top-level val on a file-wide @JsExport; and the RequestInit() bug you just hit.
